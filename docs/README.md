# Documentatie

Aici se pune lucrarea scrisa, la sfarsit de semestru, cu numele exact:

    docs/lucrare.docx

Numele se scrie cu litera mica si cu extensia .docx. Verificarea automata cauta lucrarea la
aceasta cale si nicaieri altundeva: un fisier numit altfel sau pus in radacina repository-ului
inseamna lucrare nepredata.

Lucrarea nu se incarca pe Campus Virtual. Acolo se predau doar link-ul acestui repository si
link-ul imaginii publicate in GHCR.

Nu stergeti acest folder si nu stergeti acest fisier.
